# この資料の読み方

## 何をする資料か

アルゴリズムの是非をめぐる議論は、しばしば噛み合いません。片方が
「精度が上がったのだから良い」と言い、もう片方が「精度の問題ではない」と返す。
このすれ違いの多くは、**正義について異なる前提を置いている**ことから生じます。

この資料は、その前提を表に出します。論点ごとに、主要な立場が何を重視し、
どこで結論が分かれるのかを並べます。

## 何をしない資料か

**どの立場が正しいかを決めません。** 功利主義が優れているとも、
ロールズが決着をつけたとも書きません。それは読む人が引き受ける判断です。

また、**特定の企業や製品を評価しません。** 事例は論点を説明するために
用いますが、個別の是非を裁定する目的では扱いません。

## 構成

```
docs/
  traditions/   正義をめぐる立場。何を最終的な基準に置くか
  issues/       アルゴリズムをめぐる論点。技術的な問いと規範的な問いの接点
  map.md        両者の対応表
```

立場と論点は、どちらから読んでも構いません。技術側から入るなら `issues/`、
哲学側から入るなら `traditions/` が読みやすいはずです。

## 各項目の形式

論点の項目は、次の順で書かれています。

1. **何が問題か** — 規範的な問いとして定式化する
2. **具体的な現れ方** — 実際の場面でどう立ち現れるか
3. **各立場からの見え方** — 立場ごとの評価と、その根拠
4. **未解決の点** — どの立場でも答えが出ていない部分
5. **文献** — 議論の出発点になる主要な文献

## 用語について

- **公正性（fairness）** — 技術文献では統計的な性質を指すことが多く、
  哲学の「正義（justice）」より狭い意味で使われます。両者を区別して用います
- **アルゴリズム** — 統計的な予測に基づいて人に影響する判断を下す仕組み全般を
  指します。機械学習に限りません
