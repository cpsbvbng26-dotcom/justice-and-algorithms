# 対応表

論点ごとに、各立場が**何を決め手にするか**を並べたものです。
結論そのものではなく、結論に至る根拠の違いに注目してください。

## 何を最終的な基準に置くか

| 立場 | 基準 | 問いの形 |
| --- | --- | --- |
| [功利主義](traditions/utilitarianism.md) | 効用の総和 | 全体としてどれだけ良くなるか |
| [義務論](traditions/deontology.md) | 人格の尊重 | この人は手段としてのみ扱われていないか |
| [リバタリアニズム](traditions/libertarianism.md) | 自己所有と手続き | 強制や詐欺はあったか |
| [公正としての正義](traditions/rawls.md) | 最も不利な立場 | 最も不利な人の状況は改善するか |
| [共同体論](traditions/communitarianism.md) | 財の目的と共同体の価値 | この営みは何のためにあるのか |
| [潜在能力](traditions/capability.md) | 実質的な自由 | この人は実際に何をなしうるか |

## 論点との交差

| 論点 | 最も強く反応する立場 | その理由 |
| --- | --- | --- |
| [公正性指標の両立不能性](issues/fairness-metrics.md) | ロールズ / 義務論 | 誤りの負担が特定集団に集中するため |
| [差別的効果](issues/disparate-impact.md) | ロールズ / 共同体論 | 機会均等と歴史的不正の継承に関わるため |
| [説明可能性](issues/explainability.md) | 義務論 / ロールズ | 権利と正統性の問題として立ち上がるため |
| [答責性](issues/accountability.md) | 義務論 / 潜在能力 | 帰責と救済可能性が分かれ目になるため |
| [自律とナッジ](issues/autonomy.md) | 義務論 / リバタリアニズム | 操作と自由の境界が争点になるため |

## 立場が分かれやすい問い

以下は、立場によって答えが正面から食い違う問いです。
議論が噛み合わないときは、たいていこのどれかが伏在しています。

1. **全体の改善は、特定集団の悪化を正当化するか**
   功利主義は条件付きで肯定、ロールズと義務論は否定
2. **意図がなければ差別ではないか**
   リバタリアニズムは重視、義務論と潜在能力アプローチは意図を問わない
3. **精度が高ければ説明は不要か**
   功利主義は条件付きで肯定、義務論は否定
4. **私企業の判断は公的機関と同じ基準で評価されるか**
   リバタリアニズムは明確に区別、ロールズは基本構造への影響で判断
5. **過去のデータは中立な事実か**
   共同体論と潜在能力アプローチは否定、他は立場が分かれる
