# 正義をめぐる立場

何を最終的な基準に置くかによって、同じアルゴリズムの評価は変わります。
ここでは 6 つの立場を扱います。

| 立場 | 基準 | 問いの形 |
| --- | --- | --- |
| [功利主義](utilitarianism.md) | 効用の総和 | 全体としてどれだけ良くなるか |
| [義務論](deontology.md) | 人格の尊重 | この人は手段としてのみ扱われていないか |
| [リバタリアニズム](libertarianism.md) | 自己所有と手続き | 強制や詐欺はあったか |
| [公正としての正義](rawls.md) | 最も不利な立場 | 最も不利な人の状況は改善するか |
| [共同体論](communitarianism.md) | 財の目的と共同体の価値 | この営みは何のためにあるのか |
| [潜在能力アプローチ](capability.md) | 実質的な自由 | この人は実際に何をなしうるか |

各項目は **何を基準にするか / アルゴリズムとの関係 / 主な批判 / 文献** の順で
書かれています。

論点との対応は [対応表](../map.md)、資料全体の方針は
[この資料の読み方](../00-how-to-read.md) をご覧ください。
