# リバタリアニズム

## 何を基準にするか

個人の**自己所有**と、そこから導かれる所有権を最も重視します。自分の身体と
労働の成果は自分のものであり、正当な手続きで獲得され、正当に移転された
限りにおいて、結果として生じた分配は――どれほど不平等であっても――正しい。

ノージックの権原理論では、正義は結果の形（誰がどれだけ持つか）ではなく、
**そこに至る過程**で判断されます。パターンを指定して分配を是正しようとする
試みは、個人の自由な交換への継続的な介入を必要とし、それ自体が不当だと
されます。

## アルゴリズムとの関係

私企業が自社の基準で顧客を選別することは、原則として自由の行使です。
融資を断ることも、価格を変えることも、契約自由の範囲内とみなされます。

したがってこの立場からの主要な問いは、「その判断は公正か」ではなく
**「その判断は詐欺や強制を含んでいないか」**です。条件が事前に開示され、
利用者が別の選択肢を持つなら、結果の偏りそのものは不正義ではありません。

逆に、独占的な地位にある事業者が、退出の選択肢がない利用者に対して
不透明な条件を課す場合には、この立場からも批判が可能です。強制の有無が
分かれ目になります。

## 主な批判

- **出発点を問わない** — 初期保有が過去の不正に由来する場合を扱いにくい
- **形式的自由の限界** — 選択肢が事実上ないとき、契約自由は空洞化する
- **公共財を説明しにくい**
