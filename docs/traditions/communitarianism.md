# 共同体論

## 何を基準にするか

正義の原理は、個人が共同体から切り離された状態で選ぶものではなく、
**その社会が共有する善の構想**と切り離せない、と考えます。

サンデルは、無知のヴェールの下の「負荷なき自己」という想定を批判します。
現実の人は、家族、職業、共同体の歴史といった帰属をすでに背負っており、
そうした帰属を捨象した合意は、正義の根拠として薄すぎる、と。

この立場では、財の分配を論じる前に、**その財が何のためにあるのか**を問います。
フルートは誰に与えるべきか。最も上手に吹ける者か、最も貧しい者か。
答えは、フルートという財の目的をどう理解するかに依存します。

## アルゴリズムとの関係

「公正な採用アルゴリズム」を設計するには、その前に**採用とは何をする営みか**を
決めなければなりません。過去の成功者に似た人を選ぶことか、組織に欠けている
視点を補うことか、機会を広く開くことか。目的が違えば、公正な手続きも違います。

技術的な議論はしばしばこの段階を飛ばし、目的を所与として指標だけを論じます。
共同体論からの批判は、**その飛ばした部分にこそ規範的な選択がある**という
指摘です。

歴史的不正の扱いでも、この立場は独自の含意を持ちます。過去の差別の帰結を
引き継いだデータをそのまま用いることは、単なる技術的な問題ではなく、
共同体がその歴史をどう引き受けるかという問題になります。

## 主な批判

- 共有された善の構想が実在するのか、多元的な社会では疑わしい
- 既存の共同体の価値を保守しすぎる恐れがある
- 少数者の異議申立ての基盤が弱くなりうる
