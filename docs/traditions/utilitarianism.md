# 功利主義

## 何を基準にするか

行為や制度の正しさを、それがもたらす**結果**で判断します。より正確には、
影響を受けるすべての人の幸福（効用）の総和を最大にするものが正しい、と考えます。

誰の幸福も等しく一単位として数える点で、この立場は徹底して平等主義的です。
王の苦痛も物乞いの苦痛も同じ重みを持ちます。ベンサムの「各人を一人として数え、
誰も一人以上には数えない」という原則がこれを表しています。

## アルゴリズムとの関係

相性が良い立場です。効用の最大化は最適化問題として書け、機械学習の目的関数と
形式が一致します。「精度を上げれば、より多くの人が正しく扱われる」という
主張は、暗黙のうちに功利主義的です。

一方で、総和を最大にする配分は、**特定の少数者に負担を集中させても構わない**
という帰結を許します。全体の誤り率が下がるなら、ある集団の誤り率が上がっても
正当化されうる。この点が最も激しく争われます。

## 主な批判

- **分配を問わない** — 総量が同じなら、誰が得て誰が失うかを区別しない
- **権利を飲み込む** — 十分に大きな効用があれば、個人の権利の侵害も正当化されうる
- **測れないものを扱えない** — 尊厳や信頼のように、効用に還元しにくい価値を
  取りこぼす

三つ目は、アルゴリズムの評価で特に問題になります。測定できる指標だけが
目的関数に入り、測定できない価値は最適化の過程で削られていきます。
