# 潜在能力アプローチ

## 何を基準にするか

人の状態を、所有する資源や主観的な満足ではなく、**その人が実際に何をなしうるか**
（潜在能力、capability）で評価します。

同じ量の食料を与えられても、健康な人と病気の人では実現できる栄養状態が
異なります。同じ収入でも、差別を受ける人とそうでない人では、その収入で
できることが違います。センは、資源の平等が実質的な自由の平等を意味しないと
論じました。

ヌスバウムは、この考え方を人間の中心的な潜在能力のリストとして具体化しました
（生命、身体の健康、感覚と想像力と思考、実践理性、他者との連帯など）。

## アルゴリズムとの関係

この立場は、**形式的な平等の不十分さ**を指摘します。全員に同じ基準を適用する
ことは、出発点が異なる人々にとって同じ機会を意味しません。

融資審査で全員に同じ信用スコアの閾値を課すことは、形式的には平等です。
しかし、金融サービスから歴史的に排除されてきた集団は、そもそも信用履歴を
蓄積する機会を欠いています。同じ物差しを当てること自体が、既存の
潜在能力の差を固定します。

もう一つの含意は、**異議申立ての可能性**です。判断に誤りがあったとき、
それを申し立てて是正させられるかどうかは、その人の実質的な自由に直結します。
説明可能性や救済手続きは、ここでは付随的な配慮ではなく、潜在能力の一部です。

## 主な批判

- 潜在能力のリストをどう確定するかで合意が難しい
- 測定が困難で、政策評価に落としにくい
- 何をどこまで公的に保障すべきかの線引きが曖昧
