# 公正性指標の両立不能性

## 何が問題か

「公正なアルゴリズム」を作ろうとすると、まず公正性を数式で定義する必要が
あります。ところが妥当に見える定義が複数あり、**それらは同時に満たせない**
ことが証明されています。

したがって設計者は、どれを満たすかを選ばなければなりません。この選択は
技術的な最適化では決まらず、規範的な判断です。

## 具体的な現れ方

再犯リスク予測をめぐる論争が典型です。ある評価では、黒人被告のうち再犯
しなかった人が高リスクと判定される割合が、白人被告より高いとされました。
開発側は、**同じスコアなら実際の再犯率は人種によらず等しい**（較正されている）
と反論しました。

どちらも嘘ではありません。集団間で基礎的な発生率が異なるとき、次の三つは
同時には成立しないためです。

- **較正** — 同じスコアの人は、集団を問わず同じ確率で当該事象を起こす
- **偽陽性率の均等** — 事象を起こさない人が誤って高リスクとされる割合が等しい
- **偽陰性率の均等** — 事象を起こす人が誤って低リスクとされる割合が等しい

つまり「公正さ」の議論は、**どの誤りを誰に負わせるか**の議論に翻訳されます。

## 各立場からの見え方

**功利主義** — 総効用が最大になる指標を選ぶ。誤って拘束される費用と、
誤って釈放される費用を比較し、社会全体の損失が小さい方を採る。

**義務論** — 誤って拘束される人は、他者の安全という目的の手段として
扱われている。偽陽性の負担を特定集団に集中させることは、その集団の
成員を目的として遇していない。

**リバタリアニズム** — 国家が刑事手続きで用いる場合と、私企業が用いる場合を
区別する。前者は強制力の行使であり厳しい正当化を要するが、後者は契約自由の
問題として扱う。

**ロールズ** — 最も不利な立場にある集団の状況で評価する。全体の精度が
向上しても、最も誤りを被る集団の偽陽性率が上がるなら、格差原理は満たされない。
また刑事手続きは第一原理（基本的自由）に関わるため、効率との取引に馴染まない。

**共同体論** — そもそも再犯予測という営みが何のためにあるのかを問う。
危険の管理か、更生の支援か。目的が違えば、許容される誤りの型も違う。

**潜在能力アプローチ** — 誤判定を受けた人が、それを覆せるかどうかを重視する。
指標の選択より、異議申立ての実効性が問われる。

## 未解決の点

- 基礎的な発生率の差そのものが過去の不正の産物である場合、それを所与として
  較正を論じてよいのか
- 「集団」をどう定義するか。人種、性別、年齢、地域、その交差
- 指標を満たしても、そのシステムを使うべきかは別の問い
