# アルゴリズムをめぐる論点

技術的な問いと規範的な問いが交わる場所です。ここでは 5 つの論点を扱います。

| 論点 | 何が争われているか |
| --- | --- |
| [公正性指標の両立不能性](fairness-metrics.md) | 妥当に見える公正性の定義が同時に満たせない |
| [差別的効果](disparate-impact.md) | 保護属性を除いても差別的な結果が生じる |
| [説明可能性](explainability.md) | 理由を示せない判断を人に用いてよいか |
| [答責性](accountability.md) | 害が生じたとき誰が責任を負うか |
| [自律とナッジ](autonomy.md) | 誘導はどこから操作になるか |

各項目は **何が問題か / 具体的な現れ方 / 各立場からの見え方 / 未解決の点 / 文献**
の順で書かれています。

立場との対応は [対応表](../map.md)、各立場の要約は
[正義をめぐる立場](../traditions/README.md) をご覧ください。
