# 自律とナッジ

## 何が問題か

選択肢の提示の仕方を変えるだけで、人の選択は大きく変わります。
初期設定、並び順、表示のタイミング。これらの設計は避けられません。
中立な提示というものは存在しないからです。

では、望ましい方向へ人を誘導する設計は、どこまで許されるのか。
どこから**操作**になるのか。

## 具体的な現れ方

- 推薦システムが、利用者が事前に持っていた選好ではなく、
  推薦によって形成された選好を満たしている
- 解約の導線だけが著しく分かりにくい設計
- 個別化された説得が、その人の弱点に合わせて最適化される

三つ目は、従来のナッジ論が想定していなかった段階です。集団に対する
一律の設計と、個人の脆弱性を突く最適化は、質が異なります。

## 各立場からの見え方

**功利主義** — 誘導によって本人の厚生が増えるなら、原則として許容される。
問題は、誰の厚生が増えているのか（本人か事業者か）の判定にある。

**義務論** — 本人が知れば同意しないような仕方で選択を方向づけることは、
理性的な主体としての扱いに反する。透明性が鍵となり、公開されても
機能する誘導だけが許される。

**リバタリアニズム** — 強制がなければ干渉ではない、という立場と、
選択環境の操作自体が自由の侵害だとする立場に分かれる。後者は
「リバタリアン・パターナリズム」という言い方自体を矛盾と見なす。

**ロールズ** — 反省的な検討を経て市民が受け入れうる設計かを問う。
公開の場で正当化できない誘導は、正統性を欠く。

**共同体論** — 何が善き生かの構想抜きに「本人のため」は定義できない。
その構想を誰が決めるのかが問われる。

**潜在能力アプローチ** — 選択の結果ではなく、**選択する能力**が育つかを見る。
依存を深める設計は、短期的な満足を与えても潜在能力を損なう。

## 未解決の点

- 透明性の要件を満たすナッジは、効果を失うのか
- 個別化された説得と、個人に合わせた支援の線引き
- 選好が内生的に形成される場合、「本人の選好」を基準にできるのか
