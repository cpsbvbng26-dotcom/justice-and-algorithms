# デザインに関する法的な扱い

## この頁について

この頁は、このサイトの見た目の部品について、誰が作り、どこから来たかを書きます。
部品ごとの権利と許諾と、法令の条との関わりも書きます。
書いてあるのは運営者の側の理解です。
法的な助言ではありません。
弁護士の確認は受けていません。

条文は、e-Gov 法令 API から 2026-11-22 に取り寄せた写しのとおりに引きます。
その写しは、運営者の別のリポジトリの `verification/statutes-texts.json`（コミット 85dd680）にあります。
引いた条だけを、このリポジトリの [verification/statutes-texts.json](https://github.com/cpsbvbng26-dotcom/justice-and-algorithms/blob/main/verification/statutes-texts.json) に一字一句そのまま写しました。
長い条は、この頁の文が拠る項や号だけを、写しの文から一字一句そのまま切り出して置きます。
切り出したときは、どこを切り出したかを、条の名の横に書きます。
この頁に書いた事実は、`verification/check_site.js` が実際のファイルと突き合わせます。

- 動きを減らす設定（`prefers-reduced-motion`）では、色の移り変わりの時間を 0.01ms に縮めます。動きの効果（`@keyframes`）は使っていません（`verification/check_site.js`）。

- 360px の幅でも、文字を 200% にしても、頁が横へはみ出しません（`verification/check_keyboard.js`）。
